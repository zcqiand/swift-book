============================================================
        NotesApp 项目三 最终功能验收清单（v1.0 上架前）
============================================================

[ 笔记 CRUD ]
  □ 新建笔记      点「笔记」标签右上「+」，列表顶部出现「无标题笔记」
  □ 读取笔记      列表按更新时间倒序显示全部笔记，标题与日期正确
  □ 编辑笔记      点击任意行进入编辑页，改标题/正文后返回，列表同步更新
  □ 删除笔记      左滑笔记行出现红色「删除」，点击后该行消失

[ 富文本演示 ]
  □ 整段加粗     编辑页点「整段加粗」，AttributedString 演示文字立即变粗
  □ 多行正文     正文用 TextEditor 编辑，可换行写大段文字并随笔记保存

[ 插入图片 ]
  □ 选图         点编辑页「从相册选择图片」，PhotosPicker 弹出系统相册
  □ 嵌图持久化   选中图片写入 Note 的 imageData，重开该笔记图片仍在

[ 手势交互 ]
  □ 左滑删除      笔记行向左滑出现删除按钮（.swipeActions）
  □ 长按菜单      长按笔记行弹出「复制内容/分享/删除」菜单（.contextMenu）

[ 后台同步（Actor 并发安全）]
  □ 触发同步      设置页点「立即同步」，按钮短暂禁用，界面不卡
  □ 状态显示      同步完成显示带时间戳的「上次同步：…」
  □ 并发一致      并发调用 sync 后 syncedCount 确定一致（Actor 串行化生效）

[ 自动化测试（XCTest）]
  □ 全部测试通过  Xcode 26 按 Cmd+U，NoteSyncEngineTests 全绿
  □ 合并逻辑测试  新增笔记累加计数、同 id 旧版本不覆盖断言通过
  □ 错误路径测试  非法 JSON 解码抛出 DecodingError 断言通过

[ 持久化验证（SwiftData）]
  □ 重启保留      建几条笔记 → 完全退出 App → 重新打开 → 笔记仍在
  □ 配图保留      重启后笔记的配图（imageData）不丢失

[ 上架就绪（Xcode 26 / iOS 26 SDK）]
  □ Swift 6 编译  Swift 6 语言模式 + 严格并发检查下零警告编译通过
  □ 部署目标      Deployment Target 设为 iOS 26，用 iOS 26 SDK 构建
  □ 视觉规范      标签栏/导航栏自动套用 Liquid Glass 样式无异常
