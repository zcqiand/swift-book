General 标签页 / Identity 区域
─────────────────────────────────────────────
Display Name        : 笔记
    └─ 安装到手机后显示在主屏图标下方的名字，可用中文，可与项目名不同。

Bundle Identifier   : com.yourname.NotesApp
    └─ App 的全球唯一身份证，反向域名格式。
       【务必替换】把 yourname 换成你自己的唯一标识（如你的域名倒写或团队简称），
       例如 com.zhangsan.NotesApp。一旦首次上架，这个值不可再更改。

Version (市场版本号) : 1.0.0
    └─ 给「用户」看的版本号，会显示在 App Store 商店页与「设置-通用-关于本机」里。
       遵循语义化版本 主版本.次版本.修订号。功能更新时你自己决定怎么升（如 1.0.1、1.1.0）。

Build (构建号)       : 1
    └─ 给「App Store Connect」用来区分每一次上传的内部编号。
       为什么必须递增：App Store Connect 不允许同一个 Version 下出现重复的 Build 号，
       每次向同一版本上传新构建，都必须把 Build 调成比上次更大的值（1 → 2 → 3 …），
       否则上传时会直接报错「该构建版本号已存在」而被拒收。
       常见做法：Version 改了可以把 Build 重置（如新版 1.1.0 配 Build 1），
       但同一 Version 内反复上传时只能往上加。
