# Swift 从入门到项目实践 - 代码清单

> **本书配套代码示例库** — 从章节中提取的完整可运行代码

## 关于本书

Swift 是苹果平台（iOS、macOS、watchOS、tvOS）的首选开发语言，也是近年来增长最快的系统级编程语言之一。本书从零基础出发，围绕 Swift 基础语法（变量与常量、字符串、数组、字典、集合、控制流、函数、闭包、枚举、结构体与类）逐步展开，最终为读者建立完整的 Swift 语言心智模型，为后续深入苹果生态开发打下坚实基础。

本书采用"概念→代码→决策框架"的三段式结构：每个语法点先讲清"是什么"和"为什么"，再给出可直接运行的完整代码，最后归纳使用场景与避坑指南。区别于市面常见的 API 罗列式教程，本书强调**系统性与决策判断力**——学完这本书，你不只是知道 Swift 会什么，更能判断在实际项目中何时用什么、为什么。

## 本书特点

**第一，版本最新，体系完整。** 全书锁定 Swift 5.x（2025 年稳定版），覆盖从基础语法到高级特性的完整知识图谱。变量与常量、字符串、数组、字典、集合、控制流、函数、闭包、枚举、结构体与类——每一个模块都配有从零到熟练的完整学习路径。

**第二，决策框架驱动。** Swift 语言的简洁背后藏着许多"为什么"。`var` vs `let`、`struct` vs `class`、逃逸闭包 `@escaping`、可选型安全机制——本书不只是讲语法，更讲每种选择的工程理由，让读者在真实项目中做出合理判断。

**第三，代码即文档。** 每个代码文件都来自书中明确标号的代码清单（`代码清单 N-N`），可读性优先于表演性。文件名即包含章节号与内容摘要，可直接在对应章节回溯上下文。

**第四，错误即学习。** 书中特意保留了"报错演示"类文件（如漏 `case` 导致穷尽性检查失败、默认参数顺序违规、`let` 实例调用 `mutating` 方法等），帮助读者理解编译器的安全护栏机制。

## 谁应该读这本书

如果你希望系统建立 Swift 语言基础，并真正理解语言背后的设计哲学，这本书适合你。你可能是：

- 零编程基础或仅有少量其他语言经验的初学者；
- 想要转入苹果生态（iOS/macOS 开发）的求职者；
- 有其他语言背景（如 JavaScript、Python、Java）需要快速掌握 Swift 的开发者；
- 在校学生与培训机构学员，需要一份系统教程而非碎片化视频；
- 正在学习《Swift 官方文档》但缺乏实战语境指引的自学者。

## 如何使用代码

### 环境准备

- **Swift**: 5.x（推荐使用 [swift.org](https://swift.org) 安装或通过 Xcode）
- **macOS**: 13+（Ventura 或更高版本，推荐用于 Xcode 集成开发）
- **Linux**: 可通过 Swift 官方镜像在 Linux 上运行（无 GUI）
- **编辑器**: Visual Studio Code（安装 Swift 扩展）或 Xcode
- **浏览器**: 用于查阅 Swift 官方文档 [docs.swift.org](https://docs.swift.org)

### 文件命名规范

代码清单使用两种命名格式并存：

```text
chapter{章节号:03d}_code{序号}.{扩展名}
代码清单{章节号}-{序号}[（变体）].{扩展名}
```

示例：

- `chapter007_code1.swift` — 第 7 章第 1 个 Swift 代码片段
- `chapter012_code3.txt` — 第 12 章第 3 个文本/模板片段
- `代码清单13-1_ 普通枚举 TrafficLight + switch——回扣第 7 章 7.5 节穷尽性.swift` — 第 13 章代码清单 1
- `代码清单 13-4_ 三个布尔变量表达加载状态——组合空间爆炸与语义歧义.swift` — 关联值枚举对照

带「续」「（续）」「a / b / c」后缀的文件，是同一代码清单的延续片段，按字母或「续」顺序拼接为完整代码。

### 运行示例

**单文件 Swift 示例**：

```bash
swift src/代码清单13-1_ 普通枚举\ TrafficLight\ +\ switch——回扣第\ 7\ 章\ 7.5\ 节穷尽性.swift
```

**Playground 方式**（macOS）：

将 `.swift` 文件内容粘贴到 Xcode Playgrounds 中运行，适合交互式学习。

**报错演示类文件**（故意设计为编译失败）：

文件名中含"（不会编译通过）"或"（报错演示）"的文件，用于演示编译器安全检查，运行时会报错，这是预期行为。

## ⚠️ 注意事项

1. **代码版本**: 代码基于 Swift 5.x（2025 年基线）编写，运行前请确保本地 Swift 版本为 5.x
2. **macOS 优先**: 部分特性（如 Playgrounds、部分系统框架）仅在 macOS 上可用，Linux 环境下请使用命令行版 Swift
3. **报错即学习**: 书中故意设计的报错演示文件（如漏 case、默认参数顺序违规等）运行时报错是**预期行为**，不是文件损坏
4. **跨平台**: Swift 代码本身跨平台，但涉及平台特定 API（如 Darwin、DispatchQueue）时请注意目标平台兼容性
5. **章节连续性**: 本书代码清单按章节编号排列，部分章节（如第 4 章）无代码清单属于正常情况（纯概念章节）
