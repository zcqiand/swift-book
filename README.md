# Swift从入门到项目实践 - 代码清单

## 关于本书

《Swift 从入门到项目实践》是一本面向零基础读者的 Swift + SwiftUI 实战入门书，采用「半本语言基础 + 半本递进完整项目」的两段式结构：上半本 20 章系统讲透 Swift 语言核心，下半本通过三个复杂度递进的 SwiftUI 完整 App 把语法落到真实作品。全书以 Swift 6.2 + iOS 26 SDK + Xcode 26 为版本基线，全程走 SwiftUI 声明式 UI 路线，并专设 Swift 6 并发内容，把 async/await、Actor、Sendable 讲成入门标配。

语言基础部分从环境搭建、变量常量、集合、控制流，讲到可选型、函数与闭包、枚举、结构体与类、协议、泛型、错误处理，直至内存管理与并发编程；项目实践部分依次完成待办清单 App（声明式 UI、状态管理与本地持久化）、天气与网络 API App（URLSession、Codable 与异步并发）、完整笔记应用（SwiftData 持久化、多页面架构、富文本与手势、测试调试直至打包上架），读完手里是三个真实可运行的 App 作品。

如果你是完全零基础或仅有少量其他语言经验的初学者、想转入苹果生态（iOS/macOS 开发）的求职者，或有 JavaScript、Python、Java 背景需要快速掌握 Swift 的开发者，这本书适合你——它的起点是零基础，终点是能独立做出一个可上架的 iOS App。

## 本书特点

**第一，递进项目教学法。** 沿用经过市场长期验证的「语言基础 + 递进完整项目」两段式结构，三个项目复杂度逐级抬升（本地持久化 → 异步并发 → 架构与上架），用项目成就感驱动零基础读者走完全程。

**第二，Swift 6 并发入门。** 专设并发编程与并发进阶内容，对齐 WWDC25 议题，把 Swift 6 默认开启的严格并发检查与 SwiftUI 的协同讲清楚，补齐中文入门书几乎空白的部分。

**第三，代码即文档。** 每个代码文件都来自书中明确标号的代码清单（`代码清单 N-N`），文件名含章节号与内容摘要，可随时回到对应章节回溯上下文；报错演示类文件特意保留，帮读者理解编译器的安全护栏机制。

**第四，版本基线最新。** 全书代码基于 Swift 6.2 语言模式与 iOS 26 SDK 构建运行，截图与操作步骤以 Xcode 26 界面为准，不留「出版即过时」的版本代差。

## 代码清单说明

本书所有代码清单均收录于本目录，对应书稿中「代码清单 N-M」标题块。

### 运行环境

```bash
# 环境要求：macOS + Xcode 26（本书基线 Swift 6.2 / iOS 26 SDK）
xcodebuild -version
swift --version
# 命令行类清单（语法演示、脚本）保存为 .swift 文件后可直接执行
swift hello.swift
# App 项目类清单：在 Xcode 打开书中对应项目，将清单代码放入对应文件后 Cmd+R 运行
```
